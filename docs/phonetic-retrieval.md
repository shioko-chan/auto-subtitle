# 持久化发音与原生批量匹配

术语发音保存在 `databases/fan-knowledge.sqlite3` 的 `knowledge_term_pronunciations` 派生表中。入库、术语或别名更新会重新生成该记录；删除记录会清除索引。打开已有库时仅补齐或重建指纹失效的记录。指纹包含完整输入、规则版本和 Sudachi/词典版本，发音规则变化时须更新 `PHONETIC_VERSION`。

只保存完整术语、明确提供的读音及显式别名的发音，不把长标题的任意词组当作别名；排除标点和空白读音。缩写应作为别名维护。短于5字符的发音不参与模糊匹配，但仍允许术语文本和别名精确命中。

`retrieve_asr_term_references_many` 按最多64条查询分块，使用 RapidFuzz `process.cdist` 和原生 `partial_ratio`，最多8个CPU工作线程，释放GIL，不占用GPU。多别名分数归并到各自记录；精确命中仍优先。比术语发音更短的查询改用完整字符串比对，避免短查询作为长术语子串获得满分。匹配位置基于规范化后的查询发音，不是原始汉字文本的字符偏移。ASR术语检索审计记录分数、命中发音和位置。

## 分数与质量检查

新的分数是0到1的partial-Indel相似度，不等同于旧的SequenceMatcher滑窗分数。门槛为0.80：五假名术语允许一个假名替换。回归样本包含“昨日金トレプで話した”召回“筋トレ部”，以及短查询、不相关句子、标点读音和长标题普通片段的误匹配排除。真实数据检查发现旧的任意子词组会把“僕たち”召回成长歌曲标题，故已移除该发音生成规则。该门槛仅经过这些样本验证，并非完整人工标注集上的召回率保证。

## 2026-09-10 验证

- 检索、索引生命周期、入库、流水线、翻译缓存和纠错相关测试：108项通过。
- 第三个视频审计中的343条查询，在隔离数据库副本重放：578条索引记录、542个可模糊匹配发音，匹配共1.334秒（含查询规范化、精确匹配、排序；不含背景向量检索、重排序、LLM）。
- 副本首次构建/打开0.238秒；已有索引重新打开0.045秒；主库已成功构建578条派生记录。
- 实际原生模块为 `rapidfuzz.fuzz_cpp_avx2`。
- 10个相同真实查询/发音对的有限对比：旧滑窗0.0351秒，新原生算法0.000603秒；两个算法在该小样本均无过阈值命中，不能据此推断全量召回率。
- 详细数据与候选样本：`work/diagnostics/phonetic-benchmark.json`。

此改动没有重跑字幕生成，也没有修复此前诊断出的LLM上下文超限和竖屏字幕超宽。背景候选评分仍有独立的相似度计算，不应将上述1.334秒视作完整RAG耗时。
